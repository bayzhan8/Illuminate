Optimisation, drawn

Most of this subject is taught as algebra.
Most of it is actually geometry.

Ideas that are simple once you can see them usually arrive as a page of algebra with a hence in the middle. These guides run the other order. Build the sketch, push it around until it is obvious, name it last.

Every number is produced by the code beside it, in exact rational arithmetic, and asserted by a test. make verify checks the lot.
